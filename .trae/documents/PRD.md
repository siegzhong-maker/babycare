# 兜知道 (DouZhidao) - 智能育婴助手 小程序 PRD

## 1. 产品概述
**产品名称**：兜知道 (DouZhidao)
**产品定位**：基于 AI 大模型的智能育婴助手，为新手父母提供即时、专业的育儿建议和情感支持。
**核心价值**：
- **即时响应**：24小时在线，秒级回复。
- **专业可靠**：基于权威育儿知识库（Prompt Engineering），提供科学建议（非医疗诊断）。
- **情感陪伴**：不仅解决问题，还关注宝妈/宝爸的情绪健康。
- **急救指引**：关键时刻提供清晰的急救指导。

## 2. 用户角色
- **游客/普通用户**：拥有有限的免费对话次数（如 5 次），可查看部分静态内容。
- **付费会员**：解锁无限次 AI 对话，查看完整急救教程库，拥有专属电子档案。

## 3. 核心功能模块

### 3.1 首页 (Chat Interface)
- **UI 结构**：
  - 顶部：沉浸式导航栏，显示品牌名及胶囊按钮。
  - 中部：消息流区域，包含 AI 气泡（左侧）和用户气泡（右侧）。支持 Markdown 渲染。
  - 底部：
    - 快捷建议 Chips（如“宝宝发烧”、“哭闹不止”）。
    - 输入框组件（文本输入 + 发送按钮）。
    - 底部 Tab 导航（“兜兜在线”、“兜兜小本”）。
  - 悬浮按钮：急救包 (FAB)，点击跳转急救库。
- **交互流程**：
  - 用户输入文字或点击快捷建议 -> 发送请求 -> Loading 状态 -> AI 流式/打字机回复。
  - 触发“急救”关键词或点击 FAB -> 切换至急救模式（红色主题）。
  - 触发“心情”关键词 -> 切换至安抚模式（暖色主题）。
  - 免费次数用尽 -> 弹出支付拦截弹窗。

### 3.2 急救教程库 (Emergency Library)
- **功能**：展示海姆立克、高热惊厥、CPR、烫伤等急救指南。
- **展示形式**：卡片列表，点击进入详情页。
- **详情页**：视频/动图演示 + 分步骤图文解说 + 语音播报（可选）。
- **特殊交互**：一键拨打 120。

### 3.3 个人档案 (Profile/Settings)
- **功能**：记录宝宝信息（出生日期、月龄），管理会员状态。
- **交互**：模态弹窗或独立页面展示。

### 3.4 支付与会员体系
- **逻辑**：本地计数或服务端计数判断免费次数。
- **支付流程**：调用微信支付接口（模拟/真实），支付成功后更新用户状态。

## 4. 非功能性需求
- **性能**：首屏加载时间 ≤ 2.5s，包体积 ≤ 7MB (主包 ≤ 2MB)。
- **兼容性**：适配主流 iOS 和 Android 机型，适配刘海屏/动态岛。
- **网络**：弱网环境下需有重试机制和友好提示。
- **AI 服务**：使用 **OpenRouter API** 对接大模型。

## 5. UI/UX 规范
- **主色调**：
  - 默认/主色：Orange (#ff9e80 / #ff8a65) - 温暖、活力。
  - 急救色：Red (#ef4444 / #dc2626) - 警示、紧急。
  - 安抚色：Warm White / Cream - 柔和。
- **字体**：系统默认字体，阅读舒适性优先。
- **动效**：iOS 风格的页面推入/推出 (Push/Pop)，气泡上浮 (FadeInUp)。

## 6. 上线准备
- 域名配置、HTTPS 证书。
- 微信小程序后台服务器域名白名单配置。
- 隐私协议与用户服务协议。
