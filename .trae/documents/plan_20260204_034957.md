# 兜知道小程序优化计划 - MCP 架构版

## 1. 构建“基础案例数据库” (Knowledge Base)
- **文件**：新建 `miniprogram/data/knowledge_base.js`。
- **内容**：录入 5-8 个高频育婴场景（吐奶、湿疹、红屁股、肠绞痛、黑白颠倒等）的标准案例。每个案例包含`story`（经验叙述）和`solution`（标准解法）。
- **设计意图**：这是未来的 MCP Server 数据源雏形，确保 AI 输出内容的专业性和一致性。

## 2. 实现“简易 MCP 检索器” (Context Retrieval)
- **逻辑**：在 `api.js` 或 `index.js` 中增加预处理逻辑。
- **流程**：
    1.  用户输入/点击标签。
    2.  检索器扫描 `knowledge_base`。
    3.  若命中（Hit），将该案例的 JSON 数据提取出来。
    4.  动态构建 System Prompt，追加：`【参考案例数据】：${JSON.stringify(matchedCase)}`。

## 3. 首页重构：“烦恼墙” (Worry Wall)
- **UI**：使用流式布局展示数据库中的热门 `tags`。
- **交互**：点击标签直接触发“检索 -> 发送”流程，确保用户得到的是基于“数据库案例”的回复，而非通用回复。

## 4. 移除旧功能
- 移除旧的宫格导航和不相关的代码。

此方案实现了**数据（Data）与模型（Model）的分离**，让“金牌月嫂”的经验变得有据可依。
