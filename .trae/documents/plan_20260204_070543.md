# 兜知道 - API 降级与测试用例植入计划

为了提升系统的稳定性并方便验收测试，我们将执行以下改进：

## 1. 稳定性升级：API 自动降级机制 (Auto-Fallback)
修改 `src/app/api/chat/route.js`：
- **Primary Model**: `google/gemini-3-flash-preview`
- **Fallback Model**: `google/gemini-2.0-flash-exp:free`
- **逻辑**: 使用 `try...catch` 包裹请求。如果 Primary Model 请求失败（或返回非 200），自动发起第二次请求调用 Fallback Model。

## 2. 内容升级：全场景测试用例植入
更新 `src/data/knowledge_base.js` 和 `src/app/page.js`：
- **扩充案例库**: 增加“孕期腿抽筋”、“幼儿打人”、“婴儿便秘分辨”等场景。
- **更新烦恼墙**: 将首页 Tag 更新为覆盖 -1岁到3岁的典型测试题：
    - `👣 感觉宝宝不动了`
    - `😭 一直哭`
    - `🤧 发烧了怎么办`
    - `💩 三天没拉臭臭`
    - `😡 宝宝打人`

## 3. 预期效果
- **更稳**: 即使 Gemini 3 挂了，系统也能自动切到 2.0 继续服务，用户无感知。
- **更全**: 您可以直接点击首页 Tag，验证 AI 在不同月龄段的专业表现。
