# 兜知道 - “金牌专家”角色深度植入计划

我们将基于您提供的 Prompt，对 AI 的人设、思考路径和交互逻辑进行深度升级，彻底消除“默认假设”，打造真正的专业护理专家。

## 1. Prompt Engineering 升级
修改 `src/app/page.js` 中的 System Prompt 构建逻辑：
- **Role & Goal**: 植入“金牌母婴护理专家”人设，强调“温暖、严谨、不越界”。
- **Chain of Thought**: 强制执行三步走逻辑：
    1.  **完整性自检 (Pre-Ask)**: 缺主语/月龄/症状 -> 追问。
    2.  **专业建议 (Action)**: 信息完整 -> 给 SOP。
    3.  **预测性关怀 (Post-Ask)**: 结尾 -> 主动延伸。
- **Few-Shot Learning**: 将“感冒”、“胎动”、“红屁股”三个经典范例植入 Prompt，教 AI 怎么说话。

## 2. 知识库重构：消灭歧义
修改 `src/data/knowledge_base.js`：
- **拆分“吃完就吐”**：
    - 原 `case_spit_milk` 改为仅针对宝宝。
    - 新增 `case_vomit_ambiguous` (歧义入口)，关联标签“吃完就吐”，并配置 `clarify_options` 指向“宝宝吐奶”和“孕妈孕吐”。
- **优化其他模糊场景**：
    - 检查“拉肚子”、“发烧”、“便秘”是否都具备歧义配置。

## 3. UI 微调
- 调整 `ClarifyCard` 的文案，使其语气更像“反向追问”而非冷冰冰的选项。
