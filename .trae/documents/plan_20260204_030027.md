# 2. Resolve "No Experience Permission" (暂无体验权限)
The screenshot shows a **"暂无体验权限" (No Experience Permission)** error. This is a WeChat platform restriction, not a code bug.

**Cause:**
The QR code generated by the developer tool is a **Development/Preview Version**. By default, only the project administrator and added members can view it. Strangers or unadded users cannot open it.

**Solution:**
You need to add the other person's WeChat account to the project whitelist:
1.  Log in to the **[WeChat Official Accounts Platform](https://mp.weixin.qq.com/)**.
2.  Go to **Management (管理) -> Member Management (成员管理)**.
3.  Click **Add Member (添加成员)** -> Enter their WeChat ID -> Check **Experiencer (体验者)** permissions.
4.  Once added, they will be able to scan the QR code and open the Mini Program.
