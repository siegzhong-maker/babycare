# 兜知道 Web 版 - 全周期母婴智能助手改造计划

我们将构建一个具备 **“提问前引导 + 提问中澄清 + 提问后延伸”** 完整链路的专业助手，覆盖孕期到3岁全场景。

## 1. 知识库扩容：全周期覆盖 (Lifecycle Coverage)
扩充 `knowledge_base.js`，增加**多维度场景**：
- **孕期 (Pregnancy)**：`case_fetal_movement` (如何数胎动)、`case_morning_sickness` (孕吐缓解)。
- **婴幼儿 (Toddler 1-3y)**：`case_tantrum` (发脾气/Terrible Two)、`case_picky_eater` (挑食)。
- **通用健康**：`case_cold_family` (家庭感冒应对：区分大人/小孩)。

## 2. 交互引擎升级：双向追问系统
- **提问前 (Pre-Inquiry)**：
    - 升级 `WorryWall` 组件：根据 `userProfile` (如：孕28周 vs 宝宝6个月) **动态展示** 不同的 Tag。
    - *示例*：孕妈看到的是“胎动减少怎么办”，宝妈看到的是“吐奶”。
- **提问中 (In-Inquiry)**：
    - 引入 `action: "clarify"`。当用户输入模糊（如“感冒了”）时，AI **不输出长文**，而是输出一组 **Clarification Options** (如 [宝宝感冒] [妈妈感冒])。
    - 前端 `ChatInterface` 适配这种“选项卡”交互。
- **提问后 (Post-Inquiry)**：
    - 强制 AI 在 SOP 结束后，生成 2-3 个 **Deep Dive Suggestions** (深度追问)。
    - *示例*：讲完感冒护理后，推荐问：“感冒会传染给爸爸吗？”、“什么时候需要去医院？”

## 3. System Prompt 迭代：角色与逻辑
- **角色定义**：定义为“全周期育儿顾问”。
- **逻辑约束**：
    - **Context Awareness**：始终基于宝宝月龄/孕周回答。
    - **Ambiguity Check**：遇到模糊问题（如“怎么吃”）必须先反问（“是问辅食还是奶粉？”）。

## 4. 开发任务清单
1.  **数据层**：重构 `knowledge_base.js`，增加孕期和幼儿案例，增加 `clarify_options` 字段。
2.  **逻辑层**：修改 `/api/chat/route.js`，支持根据 Knowledge Base 的配置触发追问逻辑。
3.  **UI层**：开发 `ClarifyCard` 组件，展示追问选项。
4.  **UI层**：优化 `WorryWall`，支持基于 Profile 的动态展示（Mock 数据模拟不同阶段）。
