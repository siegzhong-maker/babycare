# UI Design Document

## 1. Design System
- **Color Palette**:
  - Primary: Soft Coral (`#FF9A9E`) or Sky Blue (`#A1C4FD`) - TBD based on "Baby Care" theme.
  - Background: Off-white / Warm Gray (`#FAFAFA`).
  - Text: Dark Gray (`#333333`) for readability, not pure black.
- **Typography**: Rounded, friendly sans-serif fonts.
- **Spacing**: 4px grid system.

## 2. Layout Structure
- **Mobile-First**: Bottom navigation bar for primary access.
- **Desktop**: Responsive layout with sidebar navigation.

## 3. Key Screens

### 3.1 Home / Dashboard
- **Header**: Greeting, Current Baby selector.
- **Quick Actions**: Large buttons for AI Tools (Cry, Poop, Recipe).
- **Daily Tips**: Dynamic content card.

### 3.2 Tools Page
- Grid view of all available AI tools.
- Recent usage history.

### 3.3 Recipe / Discovery
- Search bar with filters (Age, Ingredient).
- Horizontal scroll for categories.
- Vertical feed for recipe cards.

### 3.4 Profile
- User avatar and info.
- Baby management list.
- Settings.
