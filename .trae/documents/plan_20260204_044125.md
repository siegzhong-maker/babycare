# 兜知道 Web 版重构计划 (Next.js + Vercel)

为实现敏捷开发并完美适配 Vercel 部署，我们将采用 Next.js 全栈框架。

## 1. 技术栈升级
- **Framework**: Next.js 14 (App Router) - Vercel 官方推荐，部署极速。
- **Styling**: Tailwind CSS - 快速构建移动端 UI。
- **Icons**: Lucide React - 现代化图标库。
- **Deployment**: Vercel - 自动化 CI/CD。

## 2. 核心架构设计

### 安全性升级 (API Proxy)
- **现状**: 小程序直接在前端调用 OpenRouter，Web 端这样做会泄露 API Key。
- **改进**: 创建 Next.js API Route (`/app/api/chat/route.js`)。
    - 前端请求 -> Next.js 后端 (注入环境变量 API Key) -> OpenRouter。
    - 这样 API Key 永远不会暴露给浏览器端用户。

### 组件迁移策略
- **Mobile-First Layout**: 使用 Tailwind 的 `max-w-md mx-auto` 模拟手机视口，确保在 PC 上也能优雅展示。
- **核心组件**:
    - `ChatContainer`: 管理对话流、自动滚动。
    - `SopCard`: 移植 SOP 步骤逻辑。
    - `WorryWall`: 移植烦恼墙逻辑。

## 3. 执行步骤
1.  **初始化**: 在 `web-app` 目录创建 Next.js 项目。
2.  **迁移数据**: 搬运 `knowledge_base.js`。
3.  **后端开发**: 实现 `/api/chat` 代理接口。
4.  **前端开发**: 还原聊天界面与交互逻辑。
5.  **部署准备**: 生成 `README.md` 指导如何连接 Vercel 仓库。
