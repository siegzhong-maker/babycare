# 排查“已添加权限仍提示无权限”的问题

如果后台已经显示添加成功，但用户扫码仍提示无权限，通常是以下原因导致的。我们将逐一排查：

## 1. 确认扫码的二维码版本
*   **原因**：开发者工具生成的二维码有时是“真机调试码”（有效期短，仅限本人）而不是“体验版二维码”。
*   **解决**：
    1.  请在开发者工具顶部点击 **“上传”** 按钮，填写版本号（如 1.0.1）并上传代码。
    2.  登录 [微信公众平台](https://mp.weixin.qq.com/) -> **版本管理**。
    3.  在“开发版本”列表中，找到刚才上传的版本，点击右侧的 **“选为体验版”**。
    4.  点击 **“体验版二维码”**，将**这个二维码**截图发给朋友。
    *   *注意：不要直接拍开发者工具预览界面的二维码，那个往往有权限限制。*

## 2. 确认微信号是否正确
*   有时通过昵称搜索可能加错人，或者用户有多个微信号。请确认添加的微信号与他扫码的微信是同一个账号。

## 3. 缓存问题
*   让朋友**彻底关闭微信**（后台杀掉进程）再重新打开扫码。
*   或者让他先删除该小程序的访问记录（在微信“发现-小程序”中左滑删除“兜知道”）。

## 下一步行动
我将指导您在开发者工具中执行标准的**“上传 -> 设为体验版”**流程，这是最稳妥的方法。
